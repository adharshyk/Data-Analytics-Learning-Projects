# Financial Transaction & Customer Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze financial transaction performance, customer behavior, and transaction patterns to support data-driven business decisions.

## Business Objective

The project analyzes **50,069 financial transactions** across **5,000 customers** to help understand:

- Transaction value and volume trends
- Customer segment and geographic performance
- Transaction types, channels, and merchant categories
- Transaction status and fee performance
- Potential fraud and risk indicators
- Individual transaction-level activity

## Key Features

- Interactive KPI dashboard for transaction performance
- Dynamic metric selection using DAX
- Customer and transaction segmentation
- Year, occupation, merchant category, and status filtering
- Transaction-level analysis for operational investigation
- Interactive Power BI visualizations and navigation

## Tools & Technologies

- **Power BI**
- **DAX**
- **Power Query**
- **Data Modeling**
- **Data Visualization**

## Dataset

The analysis uses two datasets:

- `finance_transactions.csv` — 50,069 transaction records
- `customers.csv` — 5,000 customer records

The datasets are connected through `customer_id`, with a dedicated Calendar table supporting time-based analysis.

## Dashboard

### Overview Analysis
Provides a high-level view of transaction performance, customer segments, transaction types, channels, merchant categories, and geographic patterns.

### Transactions
Provides detailed transaction-level information for filtering and investigating individual transactions.

## Business Value

The dashboard provides stakeholders with a centralized view of **transaction performance, customer behavior, operational activity, and risk indicators**, enabling faster identification of trends and areas requiring further investigation.
